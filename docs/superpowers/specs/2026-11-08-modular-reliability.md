# 模块化与运行可靠性设计

保留当前四个展厅的视觉、内容和交互，把组织方式改为可独立修改、可恢复、可扩展的章节系统。以本次开始时的工作目录为基线，保留已有未提交修改。既有 FutureDrive 教学功能计划继续作为后续需求。

入口只做装配。注册表声明章节编号、菜单、布局和动态 import。章节拥有自己的 view、data、controller；通用接口为 `setActive(active: boolean)`、`dispose()`。所有章节 DOM 查询限定在宿主内，不依赖全局 chapter:change 广播。

运行时负责并发加载去重、切换后迟到结果处理、错误隔离、明确重试和最终销毁。导航支持合法 hash、未知 hash 回退、浏览器前进后退；编号与总数由注册表产生。隐藏章节或后台文档不得继续运行渲染/教学计时器。

模型加载使用有时间上限、可取消的获取方式，保留 03/04 已有降级效果；02 无法加载时提供重新加载入口。共享资源清理避免重复释放同一纹理。开发热更新销毁旧应用。05 可通过新增目录和注册项接入。

不引入 React、后端、数据库、服务定位器或尚未使用的学习持久化层。只引入验证所需的开发依赖。CSS 拆分保持原来的级联次序。
